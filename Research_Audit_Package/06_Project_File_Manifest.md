## FILE DEPENDENCY MAP

```
main.py
  ├── imports data_fetcher.py → run_phase_1()
  │     └── fetch_sentinel_imagery() × 2 (pre, post)
  │           └── Planetary Computer STAC API
  │                 → data/pre/*.tif
  │                 → data/post/*.tif
  │
  ├── imports change_detection.py → run_phase_2()
  │     ├── get_alos_dem()
  │     │     └── Planetary Computer STAC API
  │     │           → data/dem/alos_slope.tif
  │     └── generate_prompts(pre_tif, post_tif, slope_tif)
  │           └── returns: list of (lon, lat) point prompts
  │
  └── imports segmentation.py → run_segmentation()
        ├── SamGeo(vit_b)
        ├── sam.set_image(post_tif)
        ├── sam.predict(points)
        ├── sam.save_prediction() → data/results/landslide_mask.tif
        └── sam.tiff_to_geojson() → data/results/landslides.geojson

validation.R (run independently)
  ├── reads data/dem/alos_slope.tif
  ├── reads data/results/landslides.geojson
  └── writes data/results/susceptibility.tif
```
